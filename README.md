# 🌻 植物大战僵尸 - Web Game 🧟

基于原生 HTML5 + JavaScript + CSS3 开发的植物大战僵尸网页游戏。

## 快速启动

```bash
docker-compose up --build -d
```

浏览器访问 http://localhost:8081

## 服务信息

| 服务名 | 端口 | 说明 |
|--------|------|------|
| frontend-user | 8081 | 前端游戏界面 (Nginx) |


## 测试账号

本项目为纯前端游戏，无需登录账号，打开浏览器即可游玩。

## 题目内容

做一个植物大战僵尸的游戏。网页是html。植物有20种。僵尸有10种。

## 项目介绍

这是一个基于原生 HTML5 + JavaScript + CSS3 开发的植物大战僵尸网页游戏。无需任何框架依赖，纯前端实现，通过 Canvas 渲染游戏画面，支持 Docker 一键部署。游戏包含 20 种功能各异的植物和 10 种特性不同的僵尸，拥有完整的阳光经济系统、波次推进机制和胜负判定逻辑。

### 游戏机制

- 5 行 × 9 列经典草坪布局
- 阳光收集系统（天空掉落 + 向日葵生产）
- 10 波次递进难度
- 僵尸分层渲染（SVG 下半身 + Emoji 上半身 + 装备叠加）
- 弹药系统（直线、抛物线、多方向）
- 火炬树桩转化豌豆为火焰豌豆
- 磁力菇吸取金属防具
- 爆炸和粒子特效

### 操作说明

- 鼠标左键：选择植物 / 种植 / 收集阳光
- 鼠标右键：取消选择

```
    ├── package-lock.json             # npm依赖锁定文件
    └── src/                          # 源代码目录

            │   ├── constants.js      # 游戏常量（网格/阳光/速度等）
            │   ├── plants.js         # 20种植物数据配置
            │   ├── zombies.js        # 10种僵尸数据与10波次配置
            │   └── zombieSprites.js  # 僵尸SVG精灵图与装备定义

            │   ├── engine.js         # 游戏引擎（主循环/种植/碰撞）

            │   ├── projectile.js     # 弹药系统（直线/抛物线/多方向）

            │   └── zombie.js         # 僵尸实体与僵尸管理器

            │   ├── plantRenderer.js  # 植物渲染（Emoji预渲染+动画）

            ├── ui/                   # UI界面目录

            │   ├── almanac.js        # 图鉴界面（植物/僵尸浏览）
            │   └── gameUI.js         # 游戏UI（植物栏/暂停/确认框/结算）

                ├── helpers.js        # 工具函数（坐标转换/距离计算）
                └── toast.js          # Toast提示系统
```

## 技术栈

- HTML5 Canvas 游戏渲染
- 原生 JavaScript（无框架依赖）
- CSS3 动画与渐变
- SVG 精灵图（僵尸下半身与装备）
- Emoji 图标系统
- Nginx 静态文件服务
- Docker 容器化部署
